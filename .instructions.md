# Instrucciones para Claude - Listy Web Project

## Resumen del Proyecto

**Proyecto:** Listy Web - Aplicación Ionic/Angular para gestión de contenido de redes sociales
**Stack:** Ionic 7+, Angular 17+, TypeScript, SCSS, Capacitor (Android)
**Propósito:** Visualizar y gestionar contenido de Instagram, Facebook, TikTok, Twitter, YouTube, LinkedIn, Telegram

## Embeds y Popups

### Scripts Externos de Embeds

| Plataforma | Script |
|------------|--------|
| Instagram | `https://www.instagram.com/embed.js` |
| Facebook | `https://connect.facebook.net/en_US/sdk.js` |
| TikTok | `https://www.tiktok.com/embed.js` |
| Twitter/X | `https://platform.twitter.com/widgets.js` |
| LinkedIn | `https://platform.linkedin.com/in.js` |
| Telegram | `https://telegram.org/js/telegram-widget.js` |

### Flujo Recomendado: Preview + Modal

1. **En el feed:** Mostrar sólo preview (imagen, título, icono de plataforma)
2. **En la BD:** Guardar metadata (`title`, `image`, `embedUrl`, `provider`)
3. **Al hacer click:** Llamar API para obtener datos completos
4. **En el popup:** Cargar el embed/iframe

**Beneficio:** Evita saturar APIs externas y bloqueos por abuso.

### ViewTiktokComponent (Patrón de referencia para modales de plataforma)

```typescript
export class ViewTiktokComponent implements OnInit {
  public id: any;
  tiktokId!: string;
  autor!: string;
  loading = true;
  safeTikTokUrl!: SafeResourceUrl;

  constructor(
    private navParams: NavParams,
    private modalCtrl: ModalController,
    private sanitizer: DomSanitizer
  ) {}

  ngOnInit() {
    this.id = this.navParams.get('id');
    this.autor = this.id.autorlink.split('@');
    this.tiktokId = this.id.id;
    this.safeTikTokUrl = this.sanitizer.bypassSecurityTrustResourceUrl(
      `https://www.tiktok.com/embed/v2/${this.tiktokId}`
    );
  }

  close() { this.modalCtrl.dismiss(); }
  onIframeLoad() { this.loading = false; }
}
```

## Flujo para Nuevas Features

1. **Crear componente** en `src/app/shared/` (reutilizable) o `src/app/pages/` (página)
2. **Crear servicio** en `src/app/services/` si necesita acceso a API
3. **Registrar la ruta** en `src/app/app.routes.ts` con guard si aplica
4. **Usar PopupService** para modales y overlays
5. **Usar PostFacade** para operaciones con posts/listas
6. **Implementar cleanup** en `ngOnDestroy` (unsubscribe con `takeUntil`)
7. **Agregar notificaciones** con ToastrService para feedback al usuario
8. **Probar en navegador** con `ionic serve`

## Consideraciones Especiales

### Embeds de Redes Sociales

- No cargar todos los embeds en el feed simultáneamente (saturación de APIs)
- Mostrar sólo previews en el feed; cargar el embed real sólo en el popup/modal
- Reprocesar embeds después de insertar dinámicamente en el DOM

### CORS y Seguridad

- Los scripts externos (Instagram, TikTok, etc.) manejan CORS por su cuenta
- Usar `sanitizer.bypassSecurityTrustResourceUrl()` **sólo con URLs confiables y validadas**
- No permitir URLs arbitrarias del usuario sin validación previa

### Performance

- Usar `ChangeDetectionStrategy.OnPush` cuando sea posible
- Lazy-load de componentes en rutas (ya configurado en `app.routes.ts`)
- Cachear datos en facade/servicios para evitar llamadas repetidas
- Limitar llamadas a API con debounce/throttle donde aplique
- Usar `loading="lazy"` en imágenes `<img>`
